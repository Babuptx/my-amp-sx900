Hi-Res Digital System SX-900

Version: 1.3.0 Gold Edition



Live Demo: https://sx900.netlify.app



📻 Overview

A professional-grade digital media player and radio tuner designed with a vintage audiophile aesthetic. This system mimics high-end receiver hardware, featuring functional VU meters, a pitch-controlled turntable, and a multi-channel radio dial.



✨ Key Features

Audiophile Interface: Realistic faceplate with a prominently sized, glowing neon-green power button.



Dual JBL Speakers: Mirrored tweeter alignment with custom white-cone dome details.



Interactive Turntable: Functional pitch slider with a real-time value display and standard +/- 8% range.



Multi-Channel Radio: A 6-channel analog-style dial pad linked to stable digital streams including KISS FM and Capital UK.



Media Deck: Load local MP3 folders with automatic playlist generation and track info.



🛠️ Technical Setup

Frontend: HTML5, CSS3 (Modern Flexbox layout), and Vanilla JavaScript.



Audio Engine: Web Audio API for real-time visualization and filtering.



Deployment: Version controlled via GitHub and hosted on Netlify.
